🚀 EchoBoard
EchoBoard is a MERN-stack social networking platform that combines content sharing, real-time communication, and AI-powered content generation into a single application.

 
 🌟 Features

📝 EchoWall
* Create and share posts
* Explore community content
* User-friendly social feed

💬 EchoChat
* Real-time messaging using Socket.IO
* Instant communication between users
* Interactive chat experience

🤖 EchoAI
* AI-powered caption generation
* Blog and content idea generation
* Helps users create engaging content quickly
* Reduces the time spent writing posts compared to traditional platforms


👤 Profile Management
* Update personal information
* Manage profile details
* Customize user profiles

🔐 Authentication & Security
* User Registration & Login
* JWT-based Authentication
* Protected Routes
* Secure Password Handling

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/MohdArham421/ECHOBOARD.git
cd ECHOBOARD
```



 Backend Setup

```bash
cd backend
npm install
npm run dev
```

 Frontend Setup

```bash
cd frontend/echo-board
npm install
npm run dev
```
